# Code of conduct

## The short version

Be decent. Assume the other person is trying to help. Argue with the idea, not
with the person holding it.

## What is expected

- Discuss the work, not the worth of the people doing it.
- Accept that "I was wrong" is a normal and useful sentence.
- Remember that a lot of people here are not writing in their first language.
- Keep disagreements technical and specific. "This threshold is unsourced" is
  useful. "This is sloppy" is not.

## What is not

Harassment, insults, or personal attacks. Sexualised language or imagery.
Publishing anyone's private information. Sustained disruption of discussion.
Any of the above dressed up as a joke.

## Scope

This applies in issues, pull requests, commit messages, and anywhere someone is
representing the project.

## Enforcement

Report a problem to the maintainer through
[GitHub](https://github.com/adarshcod30). Reports are handled privately.
Responses range from a request to change behaviour, to removing comments, to
blocking an account, depending on what happened.

This is adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, shortened to what a project this size can actually enforce.
